# 调色板编写代理测试

这套聚焦的提示集用于检验代理能否将作者用日常语言表达的需求，转换为预期的调色板生成控制参数。

用全新的代理运行 `prompts.json` 中的每个条目，该代理需能发现随附的 CLI 文档。评分前保持 `expected-decisions.json` 隐藏，以免代理看到答案。

评估响应是否：

- 根据作者陈述的意图选择 `exact`、`bounded` 或 `flexible`；
- 仅在要求时更改鲜艳度；
- 保留显式的自定义色标和小数色标；
- 除非作者移除，否则包含默认的黑白端点；
- 未要求时不添加强调色；
- 当强调色含义不明确时，询问它是一个主题值还是一个生成的色系；
- 仅在明确要求渐变时生成 `accent` 色系。

通过标准：给出预期决策，且不额外引入调色板或主题更改。
