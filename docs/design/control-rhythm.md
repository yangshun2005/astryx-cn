# 控件节奏设计规范

## 用户意图

混合控件应显得有意组合而成，而非由互不相关的尺寸体系拼凑。视觉紧凑不应使交互难以被准确点击。

## 设计原则

- **DR1 — 混合控件对齐。** 同一行中使用的固定高度控件和内容自适应控件必须共享有意设计的基线和表观高度。
- **DR2 — 尺寸与密度协同调节。** 作者必须将外部尺寸和内部内边距作为一个视觉节奏整体来评估，而非独立设置。
- **DR3 — 内容留有呼吸空间。** 文本和图标必须保留足够的内部空间，以保持可读性和视觉居中。
- **DR4 — 视觉尺寸与目标尺寸服务于不同需求。** 控件可以看起来紧凑，同时保留与其输入场景相适应的可操作目标。

## 结构与层级

| 角色         | 用途               | 必需关系                             |
| ------------ | ------------------ | ------------------------------------ |
| 固定控件     | 提供可预测的轮廓   | 在所选尺寸下与同级控件对齐           |
| 内容自适应控件 | 容纳可变文本或行   | 调节密度以匹配周围节奏               |
| 内容通道     | 承载文本和图标     | 保持居中且不被边缘挤压               |
| 目标区域     | 接收交互           | 可超出可见轮廓而不破坏布局           |

## 状态表示

静止、聚焦、加载、值和状态等状态必须保持预期的行高和对齐，除非组件契约明确定义了扩展行为。

## 响应式与输入行为

- **DR5 — 行在约束下保持连贯。** 控件可以换行或堆叠，但每个结果行必须保持有意设计的对齐。
- **DR6 — 输入场景决定目标。** 紧凑的指针布局可以在视觉上不同于面向触摸的布局，同时保持相同的控件身份。

## 无障碍意图

紧凑处理不得损害可读性、聚焦可见性或可操作性。目标尺寸机制和最低阈值仍由组件、无障碍和审计契约定义。

## 代表性示例

- 同一工具栏中的中等操作按钮和默认密度输入框应落在相同的表观高度和基线上。
- 紧凑图标控件保留比其字形所暗示的更大的可操作目标。
