# 模板组合设计规范

## 用户意图

页面模板或可复用区块应看起来像有意图的产品界面，而非仅仅是组件的有效集合。它应建立清晰的阅读顺序、连贯的区域和主题安全的强调，同时将产品内容和应用外壳留给采用它的产品。

## 设计原则

- **DR1 — 布局传达目的。** 结构区域、网格和堆叠必须让页面的主要任务在阅读具体内容之前就显而易见。
- **DR2 — 视觉层级引导视线。** 大小、粗细和位置必须建立一条从页面上下文到主要内容和操作的刻意路径。
- **DR3 — 间距和对齐表达关系。** 重复的边缘、间隙和分组层级必须在整个组合中保持连贯。
- **DR4 — 组件保留其可供性。** 模板必须选择视觉语言与预期操作、导航、数据或状态角色相匹配的组件和变体。
- **DR5 — 颜色和主题保留层级。** 表面和强调色的选择必须在每个支持的主题和颜色模式下保持含义和强调。

## 结构与层级

| 角色     | 目的                             | 必需关系                                     |
| -------- | -------------------------------- | -------------------------------------------- |
| 页面上下文 | 确立用户所在位置以及该界面的用途 | 引导视觉层级，但不与主要任务竞争             |
| 结构区域 | 对导航、控件、内容或辅助信息进行分组 | 使用与其角色匹配的布局边界和间距             |
| 主要内容 | 承载页面的主要任务或信息         | 获得最强的持续层级                           |
| 主要操作 | 提供最重要的本地下一步操作       | 在其操作组中保持唯一且易于识别               |
| 辅助内容 | 添加说明、元数据或次要操作       | 保持可用，但不扁平化层级                     |
| 重复项   | 形成列表、网格、表格或卡片集合   | 在真实内容变化中保持对齐和节奏               |

## 状态表示

| 状态       | 必需表示                                     | 允许变化                                               |
| ---------- | -------------------------------------------- | ------------------------------------------------------ |
| 有数据     | 区域和层级在真实内容下保持清晰               | 内容长度和集合大小可在模板用途范围内变化               |
| 稀疏       | 空白保持有意图的分组，而非坍缩结构           | 可选的辅助区域可以消失                                 |
| 受约束     | 区域重排时不丢失阅读顺序或主要操作           | 导航和次要内容可根据家族契约移动或折叠                 |
| 浅色或深色模式 | 表面层级、对比度和强调含义保持完整           | 主题控制调色板和视觉个性                               |
| 交互       | 组件状态在更大的组合中保持可识别             | 组件保留其家族拥有的处理方式                           |

## 响应式与输入行为

- **DR6 — 重排保留阅读顺序。** 响应式变化必须保持页面上下文、主要内容、辅助区域和操作之间的关系。
- **DR7 — 集合自适应而不任意裁剪。** 重复内容必须使用在支持的宽度和真实条目长度下保持连贯的布局策略。
- **DR8 — 输入模式保持相同的任务层级。** 键盘、指针和触摸路径必须到达相同的主要任务和操作，不依赖仅悬停发现。

## 无障碍意图

视觉层级应与语义阅读顺序和焦点顺序一致。重排不得将标签、说明、错误或操作与其所服务的内容分离。主题变化必须保持可读性和状态含义，真实内容不得暴露不可访问的溢出或截断。

语义标记、组件 API、焦点管理和响应式实现属于组件、布局家族和消费者指南的范畴。

## 代表性示例

- 密集数据页面在扫视时仍暴露一个清晰的标题、控件区域、主要数据区域和操作层级。
- 卡片集合在真实标题、元数据和缺失可选内容下保持对齐和分组。
- 窄布局移动辅助区域时不改变阅读顺序或隐藏主要操作。

## 组件契约链接

未断言任何组件契约链接。所列布局家族关系为待审查候选；消费者模板仍负责使用这些家族暴露的公共契约。

## 内容边界

此文件定义模板组合的人类视觉意图。它不定义必需的 React 组件、原始 HTML 策略、图标管道、样式机制、模拟数据源、文档元数据、行数目标、审计评分或消费者说明。
