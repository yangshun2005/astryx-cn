# 减弱动效设计规范

<!-- path-applicability:v1 -->

```json
{
  "paths": ["packages/core/src/**"]
}
```

## 用户意图

要求设备减弱动效的用户，仍能看到 Astryx 展示的每一次变化，但没有位移、缩放或弹跳。在触摸屏上，变化采用交叉淡入淡出，与 iOS 的“减弱动效”和“优先交叉淡入淡出”一致；但原地值变化和悬停或选中颜色除外，它们立即生效。使用鼠标、触控板或键盘时，变化立即完成。

## 设计原则

- **DR1 — 减弱动效下无位移。** 当用户偏好减弱动效（`prefers-reduced-motion: reduce`）时，核心组件所动画的过渡——进入、退出、呈现方式切换或状态变化——不得移动、缩放、调整大小或弹跳其内容。DR2 和 DR3 规定每种指针设备下的替代行为。

## 结构与层级

| 角色       | 用途                     | 必需关系                                                       |
| -------- | ---------------------- | ---------------------------------------------------------- |
| 起始状态     | 变化前用户看到的内容             | 不移动地离开                                                     |
| 目标状态     | 变化后用户看到的内容             | 以其最终位置、大小和顺序出现                                             |
| 交叉淡入淡出   | 在触摸屏上连接两种状态            | 仅改变不透明度，200 ms 或更短                                        |
| 直接移动     | 用户用手直接移动的内容            | 跟随指针或手指，并在抛出后继续滑行（DR2）；它不是过渡                              |

## 状态表示

| 状态                          | 必需表示                                              | 允许的变化     |
| --------------------------- | ------------------------------------------------- | --------- |
| 减弱动效，粗指针                    | 仅不透明度的交叉淡入淡出，200 ms 或更短（DR2）；原地值和颜色立即生效（DR2）      | 更短的交叉淡入淡出 |
| 减弱动效，其他任意指针                 | 立即变化（DR3），触摸拖拽的释放除外（DR2）                         | 无         |
| 无减弱动效偏好，主题为 `'system'`     | 不在本记录范围内                                          | 组件和主题动效   |
| 主题为 `'always'`（DR2a）        | 同减弱动效，无论用户设置如何                                    | DR1–DR3   |

## 响应式与输入行为

- **DR2 — 触摸呈现采用交叉淡入淡出。** 在减弱动效下，当主指针为粗指针（`pointer: coarse`），或触摸拖拽的释放启动过渡时，每个 DR1 过渡必须仅改变不透明度，且必须在 200 ms 或更短时间内完成。进入的元素出现在最终位置并淡入；离开的元素在原地淡出。释放后继续抛出的动量——衰减滑行及其在边缘的停稳——属于直接移动，不进行交叉淡入淡出，正如 iOS 减弱动效下滚动仍持续减速。组件在释放时启动的过渡，如吸附到档位、关闭或翻页到目标，仍进行交叉淡入淡出。原生滚动由浏览器负责，不受影响；Astryx 在抛出后自行动画的滑行在减弱动效下表现得像原生动量。原地值变化，如进度填充的长度或其他连续值，不进行交叉淡入淡出：在减弱动效下，它在任何指针下都立即生效，不添加元素（DEC-3）。控件的悬停或选中颜色，如 SelectableCard 的选中边框和光环，也在任何指针下立即生效，与 iOS 一致（DEC-4）。按下颜色的起始同样如此。随交叉淡入淡出的部件一起变化的颜色跟随该交叉淡入淡出，如 Switch 的轨道随其滑块变化（`component:Switch` FR15）。触摸按下的释放保持其 200 ms 或更短的淡出。
- **DR2a — 主题可为所有人减弱动效。** 主题的 `reducedMotion: 'always'` 对每个人都应用 DR1–DR3，无论其设置如何；`'system'` 遵循每个人的设置（`spec:AST-108`）。任何主题选项都不会放宽 DR1–DR4。
- **DR3 — 精细指针呈现立即变化。** 在减弱动效下，当主指针不是粗指针时，其他每个 DR1 过渡必须立即完成，不带动画属性。
- **DR4 — 核心中无退出选项。** 核心组件、其 Props 及其主题值不提供在减弱动效下保留位移、缩放、弹簧或更长动画的方式，组件自身的动效设置也不覆盖 DR1–DR3。

在拖拽过程中随用户自己的指针或手指移动的内容属于直接操纵，不是 DR1 过渡；继续抛出的动量也不是（DR2）。组件在触摸拖拽释放时启动的过渡，如滑动行滑出或手指滑动后返回（`spec:AST-057` FR5），按 DR2 进行交叉淡入淡出，因为是由手指启动的；由触控板启动的过渡在粗主指针下遵循 DR2，否则遵循 DR3。任何其他过渡，如一个面板交接给另一个（`component:BottomSheetSwitcher` FR3），在粗主指针下遵循 DR2，否则遵循 DR3。

## 无障碍意图

减弱动效移除的是移动，而非信息。用户仍能感知到某物出现、离开或变化，结果与无此偏好时相同。焦点和播报不变。

## 代表性示例

- 在手机上开启减弱动效时，点击打开的菜单在其落点处淡入，而非滑入或缩放进入。
- 在手机上开启减弱动效时，点击呈现的底部面板在其静止高度处淡入，而非从底边升起。
- 在减弱动效下使用鼠标时，Tooltip、Popover 或 Dialog 在一帧内出现和消失。

## 决策日志

### DEC-1 — 减弱动效与 iOS 一致：触摸上交叉淡入淡出，其他情况立即变化

**参考：** `design:reduced-motion/DEC-1`
**决策者：** `cixzhang`，`2026-10-24`

在触摸设备上开启减弱动效的用户期望平台行为，即变化交叉淡入淡出而非移动，淡入淡出让变化可察觉且无位移。使用精细指针时变化立即发生，因此没有移动也没有等待。对所有核心组件统一规则，任何组件都不能保留其动效，意味着该偏好在各处以相同方式被遵循。

已否决：在减弱动效下保留完整动效的逐组件设置。

### DEC-2 — 抛出后的动量继续，与 iOS 一致

**参考：** `design:reduced-motion/DEC-2`
**决策者：** `cixzhang`，`2026-10-24`

在 iOS 减弱动效下，轻扫的滚动视图继续滑行并在边缘停稳；只有应用启动的过渡变为交叉淡入淡出。与此一致可让抛出感觉像用户自身的移动，并避免内容在释放时骤停，而组件启动的吸附、关闭和翻页在 DR2 下仍进行交叉淡入淡出。

已否决：在释放时交叉淡入淡出或停止动量。

### DEC-3 — 原地值变化立即生效

**参考：** `design:reduced-motion/DEC-3`
**决策者：** `cixzhang`，`2026-10-26`

进度填充的长度及类似连续值在其所在处变化；对两个长度进行交叉淡入淡出需要第二个元素，且仍会显示移动。在减弱动效下，它们在任何指针下都立即采用新值。

已否决：在触摸屏上对旧值和新值进行交叉淡入淡出。

### DEC-4 — 仅颜色变化的状态立即生效

**参考：** `design:reduced-motion/DEC-4`
**决策者：** `cixzhang`，`2026-11-03`；伴随条款依据所有者的动效规则（2026-11-04）

控件的悬停和选中颜色，以及按下颜色的起始，在其所在处变化且不移动任何东西，因此减弱动效没有可移除的内容。在减弱动效下，它们在任何指针下都立即采用新颜色，与 iOS 一致，也与原地值一致（DEC-3）。随交叉淡入淡出的部件一起变化的颜色，如 Switch 的轨道随其滑块变化，跟随该交叉淡入淡出，因此两者永远不会显示不同状态。触摸按下的释放保持其 200 ms 或更短的淡出，以确认点击。

已否决：在触摸屏上对悬停或选中颜色进行交叉淡入淡出。
