# 空间层级设计规范

## 用户意图

用户应在阅读单个标签之前就理解哪些内容属于同一组。
密集界面应保持有序，因为邻近关系表达了关联，
而不是因为每个组都被另一个容器包裹。

## 设计原则

- **DR1 — 邻近表达关联。** 紧密相关的元素必须比独立关注点靠得更近。
- **DR2 — 分隔随分组层级递增。** 间距必须从局部内容到组、从组到区块逐级增大。
- **DR3 — 空间先于包裹。** 作者应先用间距和对齐建立分组，再添加卡片或边界。
- **DR4 — 变化是有意为之。** 一个构图必须使用足够的空间对比来体现层级，而不是在所有地方套用同一间距。

## 结构与层级

| 角色           | 用途                                                     | 必需关系                                      |
| -------------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| 局部间距      | 将标签、值、图标或控件与其直接内容关联 | 小于其所属组的间距                      |
| 组间距      | 分隔同级控件或内容组                   | 大于局部间距且小于区块分隔 |
| 区块间距      | 分隔不同的关注点                                 | 足够强，能通过眯眼测试                   |
| 对齐边缘 | 跨行或跨区域连接相关内容             | 在同一分组层级内保持一致重复        |

## 状态表现

空间关系必须在有内容、稀疏、空和错误状态下均可感知。条件内容不得折叠或颠倒分组顺序。

## 响应式与输入行为

- **DR5 — 重排保持分组。** 在受限宽度下，内容可以堆叠或移动，但局部、组和区块关系必须保持可区分。
- **DR6 — 动态内容保持节奏。** 校验、辅助文本和可选操作必须与其服务的内容保持关联。

## 无障碍意图

视觉分组应与语义阅读顺序和程序化关系一致。当组需要标签、标题或其他语义边界时，空间不能是唯一信号。

## 代表性示例

- 表单在标签与字段之间使用最紧密的关系，字段之间使用较大间距，区块之间使用最大间距。
- 仪表盘先通过间距和对齐分隔区域，再添加嵌套卡片。
