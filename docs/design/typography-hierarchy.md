# 字体层级设计规范

## 用户意图

标题、正文、标签、代码和辅助文本必须清晰可辨，让用户能快速浏览界面。无论主题风格是密集还是编辑风，阅读都应保持舒适。

## 设计原则

- **DR1 — 文字角色传达用途。** 文本必须使用层级与其功能匹配的角色，而非随意选取邻近字号。
- **DR2 — 相邻角色保持可区分。** 有意义的层级必须来自字号、字重、位置上的可见对比，或有意的组合。
- **DR3 — 多行文本有阅读空间。** 正文和辅助内容必须保持舒适的行距和行宽。
- **DR4 — 主题个性保留语义。** 主题可以调整比例和密度，但标题、正文、标签和辅助角色必须保留其相对含义。

## 结构与层级

| 角色             | 用途               | 必需关系                                 |
| ---------------- | ------------------ | ---------------------------------------- |
| 展示或页面标题   | 建立最强的阅读地标 | 明显高于章节和正文内容                   |
| 章节标题         | 组织界面内的内容   | 与页面上下文和正文均不同                 |
| 正文             | 承载主要阅读内容   | 针对持续可读性优化                       |
| 标签             | 标识控件或紧凑数据 | 与其值或控件保持关联                     |
| 辅助文本         | 补充次要上下文     | 更安静但仍可读，且与禁用文本可区分       |
| 代码或数据文本   | 保留技术或表格结构 | 保持可读，不借用标题强调                 |

## 状态表现

加载、禁用、状态、选中和截断状态必须保留文字角色的身份。状态样式不得压平标题与正文的层级，也不得使辅助文本与不可用内容无法区分。

## 响应式与输入行为

- **DR5 — 行宽保持可读。** 响应式布局必须约束长文本，不得让行无限扩展。
- **DR6 — 换行保留层级。** 标签和标题可以换行，但其与受控或分组内容的关系必须保持清晰。

## 无障碍意图

文本应在支持的缩放级别、模式和主题设置下保持可读。层级不应仅依赖颜色，全大写或异常字距不应损害持续阅读。

## 代表性示例

- 页面标题、章节标题、正文段落和辅助注释在快速浏览和缩放时均保持可区分。
- 密集仪表盘和编辑风界面使用不同个性，但保留相同的语义角色顺序。
