# 形状关系设计规范

## 用户意图

嵌套表面应读作同一有意形状的组成部分。内角不应在视觉上与容器冲突，装饰性点缀不应破坏圆角表面的几何形态。

## 设计原则

- **DR1 — 圆角跟随角色。** 角的特征必须反映元素是内部内容、控件、容器、页面区域还是完全圆角形态。
- **DR2 — 嵌套曲线保持同心。** 计入内外角之间的间距后，内角与外角必须读作平行形状。
- **DR3 — 形状特征是系统性的。** 主题应连贯地调整整体锐度或圆度，而非覆盖孤立元素。
- **DR4 — 点缀尊重几何。** 边框和边缘点缀必须与角形状融合，而非明显碰撞。

## 结构与层级

| 角色       | 用途               | 必需关系                             |
| ---------- | ------------------ | ------------------------------------ |
| 外表面     | 确立包含形状       | 决定嵌套内容可用的曲线               |
| 间隔空间   | 分隔嵌套边界       | 在视觉上体现内外曲线之间的差异       |
| 内表面     | 延续包含几何       | 读作与外表面同心                     |
| 点缀边缘   | 增加强调或状态     | 跟随而非中断表面形状                 |

## 状态表示

悬停、聚焦、选中和状态边框必须保持基础几何。改变状态不得引入冲突的角系统。

## 响应式与输入行为

- **DR5 — 形状在尺寸变化后保持。** 响应式变化可以改变尺寸，但嵌套角关系必须保持连贯。
- **DR6 — 状态环跟随所有者。** 聚焦或选中处理必须沿可见的所属形状描绘，不得产生双重或不匹配的曲线。

## 无障碍意图

形状应强化边界和归属，但不得作为状态或分组的唯一信号。聚焦和状态应独立于角样式仍可感知。

## 代表性示例

- 嵌套面板的内曲线跟随其容器和间隔空间。
- 选中的圆角卡片获得整合的边界，而非与其角碰撞的粗侧条纹。
